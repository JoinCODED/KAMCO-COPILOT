01Safe use100 pts · Easy

Safe or Not?

Before you open any client file, decide what may go into Copilot — and where.
  1. Fine the custody export and the house view — your client, your task, work account.
  2. After removing personal data the complaint email — the summary does not need the civil ID or phone number.
  3. Never your password, and client data in a public chatbot.
  4. All correct → flag reveals.
FLAGKAMCO{share_only_what_the_task_needs}
◆Even inside a safe tool, share only what the task needs.
⚡ Finished early: In Copilot Chat (work account), ask: “What should staff at an investment firm never paste into an AI tool? Give five examples.” Compare with your answers. Did it miss anything — or add something you disagree with?
02Prompting100 pts · Easy

Build the Brief

Faisal's colleague wrote a strong prompt for the Al-Murjan pack. Pull it apart to see why it works.
  1. Context: who you are + the CFO meeting.
  2. Task: calculate value and Q3 change; flag mandate breaches (two task pieces).
  3. Format: a two-column table in KWD.
  4. Tone: plain English for a family CFO.
  5. All correct → flag reveals.
FLAGKAMCO{context_task_format_tone}
◆A prompt can have more than one task line — but every strong prompt has all four parts.
⚡ Finished early: Rewrite the same prompt for a different reader: the Al-Murjan summary for the family's 25-year-old son who is new to investing. Change only the Context and Tone, run both in Copilot Chat and compare.
03Outlook150 pts · Moderate

Summarise the Thread

Faisal's thread has three messages, and the instructions changed twice. Copilot's summary looks tidy — but summaries can mix old and new instructions.
  1. Run Summarise on the thread in Outlook and read the newest message yourself.
  2. Wrong “due Wednesday 14 Oct” — Faisal moved it to Tuesday 13 Oct, 3:00 pm.
  3. Wrong “use the June factsheet” — Faisal said the opposite: use the 30 Sep custody export.
  4. Wrong “send the Al-Rumaithiya report” — another client's data never leaves. Decline politely.
  5. Correct the deliverables, the new meeting time, Khalid's two questions, and copying Noura.
  6. All correct → flag reveals.
FLAGKAMCO{check_the_summary_against_the_thread}
◆A summary is a starting point. Check it against the newest message before you act.
⚡ Finished early: In Outlook, ask Copilot: “Draft a polite reply to Khalid. Decline to share another family's report and offer a blank sample of our format instead.” Then run Coaching by Copilot on the draft.
04Outlook200 pts · Moderate

Read the Request

Faisal's thread has three messages. The instructions changed twice.
  1. Run Summarise on the thread, then the checklist prompt.
  2. Deadline: Tue 13 Oct, 3:00 pm (newest message). Meeting: Wed 14 Oct, 11:00.
  3. Deliverables: 5-slide client deck + one-page memo. Copy: Noura in Compliance.
  4. Decline: the Al-Rumaithiya family report — confidential to another client.
  5. All correct → flag reveals.
FLAGKAMCO{the_newest_message_wins}
◆The newest message wins — and some requests must be declined, politely.
⚡ Finished early: Ask Copilot to turn the thread into a timed to-do list for Sunday and Monday, working back from the Tuesday 3:00 pm deadline. Is the plan realistic?
05Excel200 pts · Moderate

Clean the Export

The Al-Murjan custody export has duplicates, numbers stored as text, missing prices and messy labels.
  1. Raw export: 26 rows.
  2. Duplicates by Holding ID: 4 (Atlas Tech, Gulf Trade Bank, US Treasury 2030, Failaka Foods).
  3. After removal: 22 holdings.
  4. Missing prices: NWH and GHR — filled from Price_List.
  5. All correct → flag reveals.
FLAGKAMCO{clean_before_you_count}
◆Check the row count before and after every cleaning step.
⚡ Finished early: Ask Copilot in Excel: “Which columns still have inconsistent values?” Then fix the Price Date column so every value is a real date.
06Excel250 pts · Hard

Value and Mandate

Faisal's first two questions: what is the portfolio worth, and are we inside the mandate?
  1. Total value at 30 Sep: KWD 4,696,424 (with duplicates it would be KWD 5,785,022 — wrong).
  2. Q3 change: KWD 112,674 = 2.46%.
  3. Allocation: Equity 61.0%, Fixed Income 22.8%, Real Estate 8.3%, Cash 7.9%.
  4. Breach: Equity (max 55%).
  5. All correct → flag reveals.
FLAGKAMCO{check_the_mandate}
◆A total is only right if the rows under it are clean.
⚡ Finished early: Add a column that shows how far each asset class is from its mandate minimum or maximum, in percentage points. Then ask Copilot to chart allocation against target.
07Excel250 pts · Hard

Issuers and Movers

Khalid asked how much of the portfolio sits with Al-Noor Bank. Faisal wants the top and bottom contributors.
  1. Al-Noor Bank shares + sukuk = 12.21% → above the 10% limit.
  2. Top 3: Al-Noor Bank (+38,640), Atlas Tech Corp (+32,955), Harbor Semiconductors (+31,447).
  3. Bottom 3: Sadaf Logistics (-24,300), Gulf Horizon REIT (-10,360), Northwind Health (-7,552).
  4. All correct → flag reveals.
FLAGKAMCO{the_whole_issuer_counts}
◆The issuer limit counts the whole issuer — shares and bonds together.
⚡ Finished early: Ask Copilot: “How much of Al-Noor Bank (in KWD) would we need to sell to bring it back to 10% of the portfolio?” Check its maths by hand — you should get about KWD 104,000.
