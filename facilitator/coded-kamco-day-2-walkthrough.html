03PowerPoint150 pts · Moderate

Fix the Deck

Copilot built a 5-slide deck from your memo. Three things will lose the client.
  1. Slide 2: a topic, not a message → write the message.
  2. Slide 3: add the source under the chart.
  3. Slide 4: cut nine bullets to three.
  4. All correct → flag reveals.
FLAGKAMCO{one_slide_one_message}
◆One slide, one message — and show your source.
⚡ Finished early: Ask Copilot in PowerPoint to add an appendix slide with the full allocation table, and write speaker notes for slide 1 in Arabic.
04Outlook250 pts · Hard

Check the Reply

Copilot drafted your reply to Faisal. It took ten seconds. It has four problems.
  1. Accuracy: “up 4.6%” — it is 2.46%.
  2. Confidentiality: names another client (Al-Rumaithiya).
  3. Tone: promises Al-Noor Bank will rise.
  4. Completeness: the memo was due with the deck (Tue 3:00 pm).
  5. All correct → flag reveals.
FLAGKAMCO{verify_before_you_send}
◆Run the four checks before every send.
⚡ Finished early: Ask Copilot in Outlook to draft the client-facing version for Khalid — with the house-view disclaimer — then run the four checks on it yourself.
05Outlook150 pts · Moderate

Name the Check

Six problems found in KAMCO drafts last quarter.
  1. Accuracy: 16.0% vs 61.0%.
  2. Confidentiality: wrong recipients.
  3. Tone: the guarantee; the one-line reply.
  4. Completeness: no disclaimer; no attachment.
  5. All correct → flag reveals.
FLAGKAMCO{four_checks_every_time}
◆Accuracy · Confidentiality · Tone · Completeness.
⚡ Finished early: Write your own reply with three planted errors (one per check) and swap with your neighbour. Who finds all three first?
06Agents200 pts · Moderate

Build the Agent

You will build a Request Triage Assistant in Copilot Agent Builder.
  1. Describe one clear job.
  2. Instruction: always use the newest message.
  3. Knowledge: the house view rules.
  4. Test → fix → re-test.
  5. Share with a small pilot group.
  6. All correct → flag reveals.
FLAGKAMCO{instructions_make_the_agent}
◆An agent is only as good as its instructions.
⚡ Finished early: If Agent Builder is on for you: add two starter prompts to your agent and one rule that makes it refuse to share another client's data. Test it with Khalid's request.
