Cheat Sheet · Copilot at Work
Part 1
Ask well
Three habits that turn a vague answer into a usable one.
CTFT
The prompt recipe
Like briefing a junior analyst.
Context, Task, Format, Tone — four parts of every strong prompt.
“I manage Al-Murjan FO… summarise the 30 Sep export… five bullets in KWD… plain English for a CFO.”
TellAll four parts are there
Iterate
Refine, don't restart
Like a tailor's fitting.
Treat the first answer as a draft. Improve it in the same chat.
“Shorter. Breaches first. One decimal place.”
TellShort follow-ups, same chat
Source with /
Point at the file
Like pointing at the right folder.
Type / to choose the exact file, email or meeting Copilot must use.
“Use /amfo-q3-custody-export.xlsx (30 Sep).”
TellEvery number has a named source
CTFT = the brief · Iterate = the fitting · / = the source
Copilot drafts. People decide.
Part 2
One workflow, four apps
Request → Check → Produce → Reply.
Outlook
Read the request
Like a chief of staff's one-pager.
Summarise the thread, then turn it into a checklist: deadline, deliverable, who to copy, what not to do.
“From this thread, list the final deadline, each deliverable and its format, who to copy, and any request I should not do.”
TellThe newest message wins
Excel
Clean, then count
Like a chef's preparation.
Remove duplicates, fix text numbers, fill missing prices, clean labels — then build the PivotTable.
“Highlight duplicate rows based on Holding ID.”
TellRow count checked before and after
Word & PowerPoint
Answer first
Like a newspaper headline.
Memo when read alone; deck when presented. Bottom line first. Every slide title is the message.
“Change every slide title to one sentence that states the main message.”
TellTitles alone tell the story
Outlook = the ask · Excel = the numbers · Word / PowerPoint = the answer
Feed Copilot numbers you have checked — do not let it re-calculate them.
Part 3
The four checks — before every send
Like a pilot's checklist: every flight, every send.
Accuracy
The numbers
Like matching receipts.
Every figure matches your analysis.
4.5% is not 5.4%.
TellEach number traced to the file
Confidentiality
The people
Like a sealed envelope.
Only this client. Only the right recipients.
Never name another family.
TellNo other client, right list
Tone
The voice
Like answering in the guest's language.
Fits the reader. No promises of returns.
Remove “returns will stay strong”.
TellNo guarantee, no forecast
Completeness
Everything asked for
Like a packed suitcase.
All outputs, attachments, people copied, disclaimer if client-facing.
Memo and deck both attached.
TellNothing “to follow later”
You sign the email — not Copilot.
⚠
Agents: an agent is only as good as its instructions. Give it one job, clear rules (“always use the newest message”), the right files — and test it before you share it.
