01Crypto · Hashing200 pts · Hard

Crack the Hash

A leaked table of unsalted MD5 password hashes. Run a real dictionary attack and see which fall — and which survives.
  1. Launch the dictionary attack — the console hashes every wordlist entry and compares it to each leaked hash.
  2. Three weak hashes fall in milliseconds: j.salim → password123, a.fahad → Summer2024!, m.yousef → qwerty.
  3. The fourth, admin, is a 28-character passphrase (correct horse battery staple) — not in any practical wordlist, so it survives.
  4. 3 cracked, 1 holds → flag reveals.
FLAGKIBS{length_beats_complexity}
◆Length, not symbols, is what saved the rest. A long passphrase beats a short "complex" password.
02Crypto · Stuffing150 pts · Moderate

The Domino

A shopping site this customer used was breached — exposing rana@email.com / Rana2019!. The attacker now tries that password everywhere. At-risk = reuses the breached password AND has no MFA.
  1. ⚑ At risk Personal email — reuses the password, no MFA.
  2. ⚑ At risk Streaming service — reuses the password, no MFA.
  3. ⚑ At risk Social media — reuses the password, no MFA.
  4. ✓ Safe Online bank login — reuses the password, but MFA is on.
  5. ✓ Safe Work single sign-on — a unique password.
  6. Tick the three at-risk accounts → flag reveals.
FLAGKIBS{reuse_is_a_skeleton_key}
◆Reuse is the skeleton key; MFA breaks the chain. Either a unique password or MFA would have saved the safe accounts.
03Standards · Mapping150 pts · Moderate

Map the Control

Auditors ask which standard each control belongs to. The secret: the big frameworks overlap far more than they differ. Two of these satisfy all three at once.
  1. "Encrypt cardholder data at rest and in transit" → PCI-DSS
  2. "Maintain a certified, audited ISMS" → ISO 27001
  3. "Organise security around Identify · Protect · Detect · Respond · Recover" → NIST CSF
  4. "Enforce MFA on all administrative access" → All three
  5. "Keep and actively monitor access logs for critical systems" → All three
  6. Submit → flag reveals.
FLAGKIBS{one_control_many_frameworks}
◆One good control satisfies many frameworks at once — map once, satisfy many.
04Policy · The Gap200 pts · Hard

Mind the Gap

Classify each document as Policy (the what & why), Standard (the measurable rule), or Procedure (the step-by-step how) — and mark the one item that is a missing-procedure gap.
  1. "We protect customer data and comply with all applicable regulation." → Policy
  2. "Passwords must be at least 14 characters with MFA enabled." → Standard
  3. "Step 1: open the console … Step 5: confirm and file the wipe certificate." → Procedure
  4. "Decommissioned servers were sent to recycling, but no documented wipe procedure was ever performed." → Gap — missing
  5. "All staff complete annual security-awareness training." → Policy
  6. Submit → flag reveals.
FLAGKIBS{a_policy_without_a_procedure}
◆Exactly the Morgan Stanley failure — the policy and standard existed; the procedure never ran. A policy without a procedure is just a wish.
05Incident Response250 pts · Hard

The 02:00 Call

It's 2 a.m. A teller workstation is throwing ransom notes and files are encrypting across a shared drive. Run the incident — the right call at each phase; every wrong move makes it worse.
  1. 02:00 · Detect → Confirm scope in the SIEM, verify it's a real, active event. (Not reboot — triggers more encryption. Not wait — it spreads by the minute.)
  2. 02:08 · Contain → Isolate the affected hosts from the network (pull the cable / disable the port) without powering them off. (Powering off destroys volatile evidence; never pay.)
  3. 03:30 · Eradicate → Find the initial access, remove the malware, patch the vulnerability before reconnecting. (Don't just delete the note; don't restore onto an infected host.)
  4. 06:00 · Recover → Restore from known-clean, offline backups onto rebuilt systems, verify integrity before going live. (A recent backup may already be infected.)
  5. +1 week · Learn → Post-incident review — root cause, timeline, fix controls, retrain. (Don't just close the ticket; don't keep it quiet.)
  6. All five calls correct → flag reveals.
FLAGKIBS{contain_before_you_clean}
◆The order is everything: contain before you clean, and recover only from known-clean backups.
