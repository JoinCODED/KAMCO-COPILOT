01Crypto · Hashing200 pts

Crack the Hash

A stolen table of unsalted MD5 hashes. Crack it live and show length beating complexity.
▶Open by saying"I'll run a real dictionary attack. Watch how fast short passwords fall — and why the long one doesn't."
  1. Click Run dictionary attack — the console hashes every wordlist entry and compares.
  2. Three crack instantly: teller01 → welcome, branch.mgr → football, it.admin → admin — all short and common.
  3. The CISO's row (a 30-char passphrase, a long blue horse runs at dawn) is not in the wordlist — survived. Long, not complex.
  4. Make it explicit: an 8-char "P@ssw0rd" falls; a 30-char passphrase doesn't.
  5. Submit → flag.
FLAGKIBS{eight_characters_isnt_enough}
◆Land thisStop chasing symbols and capitals. A long passphrase of plain words beats a short "complex" password every time.
02Crypto · Stuffing150 pts

The Domino

Show how one breached password cascades across a person's accounts. Breach: maha@email.com / Maha#2020.
▶Open by saying"One leaked password. Watch how far it reaches — and where MFA stops it dead."
  1. Read the breached credential aloud — this is now public.
  2. Mark Corporate email, Cloud storage, Forum — reused password, no MFA → taken over.
  3. Leave Online banking (unique password) and Corporate VPN (MFA on) — both safe.
  4. Submit and show all green.
FLAGKIBS{one_breach_unlocks_many}
◆Land thisTwo habits defeat this entirely: a unique password per site, and MFA on anything that matters. Either one saves the safe accounts.
03Standards · Mapping150 pts

Map the Control

Demonstrate how one control can satisfy several frameworks at once — two of these satisfy all three.
▶Open by saying"Frameworks look like three separate burdens. Watch how much they overlap."
  1. "Segment the cardholder-data environment from the corporate network" → PCI-DSS
  2. "Run a documented risk assessment and Statement of Applicability" → ISO 27001
  3. "Build defined Respond and Recover capabilities for incidents" → NIST CSF
  4. "Patch known vulnerabilities on a defined, tracked schedule" → All three
  5. "Grant access to data on a least-privilege basis" → All three
FLAGKIBS{map_once_satisfy_many}
◆Land thisDon't run three parallel compliance projects. Map controls once to a common set and most frameworks fall out for free.
04Policy · The Gap200 pts

Mind the Gap

Classify the documents and expose the missing procedure live.
▶Open by saying"A bank can have every document and still fail. Watch where the gap hides."
  1. "The bank preserves the confidentiality, integrity and availability of information." → Policy
  2. "Production data must be encrypted with AES-256." → Standard
  3. "To off-board a leaver: 1) disable AD account 2) revoke VPN 3) collect devices." → Procedure
  4. "A developer left months ago but still holds an active admin account — no off-boarding was ever performed." → Gap (the procedure existed but was never run).
  5. "Access to customer data is granted on a need-to-know basis." → Policy
FLAGKIBS{the_missing_procedure}
◆Land thisAudit the doing, not just the documents. A procedure nobody follows is a gap an attacker walks straight through.
05Incident Response250 pts

The 02:00 Call

Run the incident-response decision drill in front of the room — make a wrong call or two so they see the consequence.
▶Open by saying"There's a right order, and getting it wrong turns an incident into a catastrophe. I'll make a couple of wrong calls so you can see the consequence."
  1. 02:10 · Detect → Verify the alert and scope affected hosts. (Tap a wrong option first to show the consequence message.)
  2. 02:18 · Contain → Isolate the affected hosts without powering off. Explain why powering off loses evidence.
  3. 04:00 · Eradicate → Find the entry point, remove the malware, close the vulnerability before reconnecting.
  4. 07:00 · Recover → Rebuild and restore from verified clean, offline backups before going live.
  5. +3 days · Learn → Post-incident review — fix root cause, update controls and training.
FLAGKIBS{isolate_then_eradicate_then_recover}
◆Land thisHand the room the order as a memory hook. The instinct to "just reboot and restore" is exactly what spreads ransomware and re-infects clean backups.
